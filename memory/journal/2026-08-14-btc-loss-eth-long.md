## Тезис «расхождения лонговые» — проверка

Лонговые расхождения действительно есть, вес 4:
- Спот вверх против фьючерса вниз → реальный спрос против манипуляции на
  плече, признак ложного пробоя вниз.
- Падение выкупается на споте → накопление.

Шортовые, вес 5:
- ОИ вверх + фьючерсная дельта вниз → набор под давлением продавца.
- Цена вниз при фьючерсе вниз → фьючерс подтверждает падение.
- Толпа ловит нож: L/S 2,595 растёт при падающей цене.

Ярус 1 — **состояние 3** (ОИ вверх + цена вниз), которое стратегия не торгует
ни в лонг, ни в шорт. Вход сделан против собственного вето.

Позиция открыта; задача теперь — сопровождение, а не оценка входа задним
числом.
