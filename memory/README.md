# memory/

Рабочая память торгового ассистента (`.claude/agents/trading-analyst.md`).

| Каталог | Что кладём |
|---|---|
| `journal/` | Сделки и состояние счёта |
| `strategy/` | Разборы рынка и стратегии |

Заметки — markdown, имя файла `<ГГГГ-ММ-ДД>-<тема>.md`.

## Что не коммитится

`journal/trades.jsonl` — сам журнал сделок — в `.gitignore`. Это личные
торговые данные; структура каталога версионируется, содержимое счёта нет.
Путь переопределяется переменной `IAI_TRADE_JOURNAL`.

Туда же не кладутся сырые ответы биржи (`*.raw.json`). Ключи API живут
только в окружении (`BYBIT_API_KEY`, `BYBIT_API_SECRET`) и в репозиторий не
попадают ни в каком виде.

## Журнал — только добавление

`trades.jsonl` пишется построчно и не редактируется. Каждая запись несёт
`prev_hash` предыдущей, поэтому правка задним числом рвёт цепочку:

```
python tools/diary.py verify
```

`verify` печатает три раздела — состояние цепочки, расхождения в арифметике
(с обеими цифрами и разницей) и отдельно «нет данных». Последнее — не ноль,
а отсутствие: незаполненные поля не участвуют в расчётах.
