# EVDEN TRADING — Style Pack (эталонные форматы)

> Дополнение к `evden-trading-copywriter.md`. Живые образцы постов, на которые
> ориентируется агент при генерации — не инструкция «как писать», а корпус
> примеров с разметкой, что сработало и почему.

---

## Правила площадок (уточнено пользователем 2026-08-13)

- **Telegram** — основной канал, глубокая аналитика, ведение позиций.
- **ВКонтакте** — образовательный формат, покороче. **CTA ведёт на канал ВК**
  (`https://vk.ru/im/channels/-235509006`), **не на Telegram** — аудитория
  пока целиком удерживается в ВК, кросс-постинг в TG не используется.
- **Threads** — вирусные хуки/треды. Никаких внешних ссылок в тексте, только
  отсылка к TG в профиле. Английская аудитория — отдельный поток контента
  от русской (не перевод один-в-один, разные книги/темы заходили по-разному).

## TG — эталонный скелет «Ведение позиции»

Источник: пост по BTC от 64,137.93 → 63,474.72.

```
СОПРОВОЖДЕНИЕ ПОЗИЦИИ #TICKER

Структура рынка: <консолидация/тренд, относительно POC>
Ликвидность: <нижний пул, верхний пул с суммой из CoinGlass>
Спот-поток: <дельта, направление>
Open interest: <динамика>
Фьючерс-поток: <CVD.F, Net Shorts/Longs, L/S ratio>
Orderbook: <дельта стакана>

<Один абзац причинно-следственной механики: что делает толпа, где
формируется плотность стопов, почему это меняет вероятность сценария>

Вход: $X
Маркировка: $Y
Реализовано: +$Z
Остаток: ~$N (плечо), +$P (%)
Тейк по остатку: $T

<Абзац про защиту сделки — почему локальный сквиз её не ломает,
условия для добора>
```

Ключевое: никаких лишних вводных, метрики — списком, а не прозой;
объяснение «почему» — один плотный абзац, не два.

## TG — эталонный скелет «Разбор позиции» (закрытая сделка)

Источник: пост #ZEC.

```
#TICKER: разбор позиции

Структура рынка: <где именно на диапазоне>
Ликвидность: <куда целится>
Спот-поток: <дельта + примечание>
Open interest: <динамика>
Фьючерс-поток: <дельта + позиционирование>

<Абзац: расхождение потоков и что оно означает>
<Абзац: как был построен вход/стоп/логика>

Вход: $X
Выход: $Y
Стоп: N%
Прибыль: +N%
```

## TG — короткие сигнальные посты (паттерн-заметки)

```
#TICKER

ОИ <растёт/падает> + Цена <растёт/падает> = <вывод одной строкой>

CVD.F↘️/↗️
CVD.S↘️/↗️
Bidы/Askи ↗️/↘️
```

Используется как быстрая заметка между полными разборами, без раскрытия
контекста — аудитория уже владеет нотацией.

## ВК — три поста из одного разбора

Логика нарезки одного TG-разбора на три поста для ВК:

1. **Механика** (хук на конфликт восприятия — «большинство читает это как X, это ошибка»).
2. **Инструмент** (образовательный, даёт читателю метод, а не вывод — лучше всего расшаривается).
3. **Результат** (доказательство через конкретную сделку, без хвастовства, через математику риска).

Каждый пост короче TG-версии в 2–3 раза, без таблиц, без плотной нотации —
термины расшифровываются по ходу текста. Заканчивается CTA на канал ВК.

## Threads — форматы

### Тред-разбор (RU, по мотивам «розовых очков»)

```
1/ Хук: сухая структура рынка без прикрас, 3-4 буллита с метриками.
2/ Разворот: куда идёт цена и почему («не X, а Y»).
3/ Кикер: обобщение до принципа («95% сливают не потому что...»).
```

### Тред-инсайты (книга, EN/RU раздельно)

```
1/ "I read [Автор]'s '[Книга]' [N] times. [Личный твист/переосмысление]"
2/ Инсайты 1-5, короткие пронумерованные тезисы.
3/ Инсайты 6-10 + финальный панч-кикер.
```

Заметки:
- EN-аудитория и RU-аудитория держатся раздельно, не зеркалятся дословно.
- Douglas "Trading in the Zone" — лучший результат на RU.
- Tendler "The Mental Game of Trading" — заходит на EN.

### Вопросы-хуки (отдельные посты, без ссылок)

Формат: конкретная рыночная ситуация → вопрос с двумя вариантами ответа,
провоцирующий комментарии специалистов, а не лайки.

```
Кто перед <событием> увидел <сигнал>, а не <ложную интерпретацию>?
```

```
<Метрика A> растёт, <метрика B> падает. <Вывод 1> или <вывод 2> — и почему?
```
